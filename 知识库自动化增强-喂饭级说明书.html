🚀 三步上手（总耗时约 5 分钟）

1
装 Obsidian 并打开你的库
  • 官网 obsidian.md 下载（Win/Mac 都免费），安装。
  • 打开 Obsidian → 打开其他仓库 → 通过文件夹打开 → 选中 knowledge-base/ 文件夹。
  • 首次打开会提示「启用社区插件？」→ 点 启用。配置已写好，三件套直接生效。
2
若没自动提示，手动开社区插件
  • 左下角 设置 ⚙ → 社区插件 → 关掉「安全模式」。
  • 点 已安装插件 → 应看到 QuickAdd / Templater / Dataview / Periodic Notes 已列在其中 → 把开关打开。
  • 若列表是空的：点 浏览 → 搜这 4 个名字 → 安装 → 启用。装完会自动读取我写好的 .obsidian/plugins/ 配置。
装好后如果配置被重置（很少见），照本文最下方「故障排查」手动粘贴即可。
3
验证三件套
  • QuickAdd：左侧栏出现 ⚡ 闪电图标 → 点开能看到「➕ 新四问卡」「📥 速记到捕获箱」。
  • Templater：命令面板（Ctrl/Cmd+P）搜 Templater → 确认模板文件夹是 templates。
  • Dataview：打开库里的 01-自动索引.md → 应实时显示全部卡片列表（不是代码块）。

✍️ 日常建卡流（QuickAdd 一键）

  1. 点左侧 ⚡ → 选 ➕ 新四问卡。
  2. 弹出框输入标题（如「茅台冰激凌复盘」）→ 回车。
  3. 自动在 categories/AI与方法/ 生成 YYYY-MM-DD-标题.md，已套好四问卡骨架，光标在标题处。
  4. 把内容填进四问卡 → 保存。（分类默认落到 AI与方法，建完拖到正确分类文件夹即可；或让元宝帮你归）
💡 更省事的做法：还是把链接/视频丢给元宝，它蒸馏成卡 + 自动归档 + 四端同步。QuickAdd 适合你离线想自己快速记一笔时用。

📇 Dataview 自动索引

打开 01-自动索引.md，Obsidian 会把它渲染成实时表格：

// 自动列出 categories/ 下所有卡片，按文件名倒序
TABLE file.folder AS 所在分类, file.mtime AS 最后更新
FROM "categories"
SORT file.name DESC

卡片元数据（关联度/变现）仍看 index.md（手机端 kb.html 也读它）；Dataview 负责「有哪些卡 + 一键跳转」，再也不用手动数卡。

🔄 知识迭代 Skill（扫库查冗余）

这是 WorkBuddy 侧的自动化：定期跑一遍，找出库里的「坏味道」。

检查项说明
重复标题 / 文件名同一天同名卡、近似标题
断链卡片里链接了不存在的文件
空卡 / 发育不良正文 < 200 字疑似没写完
索引遗漏index.md 漏登的卡 / 已删但还登记的
分类漂移卡放错一级分类文件夹

调用方式：跟元宝说「扫一下知识库」或「跑知识迭代」即可触发，输出一份可读报告，你决定修不修。

🛠️ 故障排查

插件装了但配置不对？

把我写好的配置重新贴回 Obsidian 的插件设置文件（在 knowledge-base/.obsidian/plugins/<插件名>/settings.json）。或最省事：卸载插件重装，会自动读回配置。

Dataview 页显示成代码而不是表格？

  • 确认 Dataview 已启用（设置 → 社区插件 → Dataview 开关开）。
  • 代码块语言必须是 dataview（不是 ```js）。

想接真·AI 对话在 Obsidian 里？

装 Copilot 插件，但需自备模型 key（OpenAI / 本地 Ollama 等），要花钱或本地算力。你不装也完全不影响——元宝才是你的主引擎。
