# 元宝知识库 · 使用说明

> 一句话：你负责「喂内容」，我负责「整理 + 分类 + 告诉你怎么用 + 跟你的项目挂钩 + 能不能挣钱」。
> 本知识库由元宝（WorkBuddy）维护，你随时在微信「文件传输助手」打开这些 md 文件就能看。

---

## 一、现在你能用的「知识获取渠道」

| 渠道 | 怎么用 | 状态 |
|------|--------|------|
| **你直接粘贴** | 把文章、视频字幕、链接、截图丢给我 | ✅ 最常用 |
| **联网搜索** | 我主动搜全网最新资讯（AI / 创业 / 财经 / 国际） | ✅ 已接 |
| **抓指定链接** | 给我一个网址，我读正文并提炼 | ✅ 已接 |
| **QQ 邮箱** | 读你的邮件、订阅的 newsletter | ✅ 已连 |
| **腾讯文档** | 读 / 写你已有的腾讯文档 | ✅ 已连 |
| **微信公众号 / 知识星球 / Notion / 飞书 / 抖音 / 小红书** | 连接对应账号后可自动读 | ⏳ 待连（在连接器里开启即可） |
| **本地文件** | 你丢文件进 `_inbox/`，我批量处理 | ✅ 已接 |

**结论**：渠道不是问题，问题是「收藏了不用」。本知识库的核心就是把「收藏」变成「喂给元宝 → 变成能用的卡片」。

---

## 二、分类体系（两级）

- **一级主题域**（固定 5 类，对应 `categories/` 下的文件夹）：
  1. `AI与方法` — AI 学习法、提示词、知识管理、工具用法
  2. `创业与变现` — 商业模式、副业、定价、增长
  3. `技术与工具` — 具体技术、部署、自动化
  4. `行业与趋势` — 赛道洞察、信息差、政策
  5. `个人成长` — 认知、习惯、决策
- **二级标签**（自由，每条自定，如 `#知识管理 #零基础`）
- **两个打分**（我每条约你打）：
  - `项目关联度`：高 / 中 / 低
  - `变现潜力`：高 / 中 / 低 + 具体路径

---

## 三、你怎么喂我内容

方式任选其一：
1. **聊天里直接贴** 文字 / 链接 / 截图 → 我当场处理归档。
2. **丢文件进 `knowledge-base/_inbox/`** → 我批量处理（支持 .md/.txt/.url）。
3. **只给一句话主题** → 我联网搜、抓、整理成卡。

每次你给我内容，我会按下面「四问」产出一张卡。

---

## 四、我每条怎么处理（四问模板）

1. **怎么用** —— 现在马上能做的 / 未来能用的，分两条列。
2. **和你之前项目的关系** —— 是否接上 mini-apps、mini-games、每日 AI 简报、GitHub 等。
3. **能不能帮你挣钱** —— 给路径（卖模板 / 订阅 / 接单 / 信息差产品），并标潜力等级。
4. **灵感延伸** —— 还能长成什么（新 app / 新自动化 / 新内容）。

## 五、目录结构

```
knowledge-base/
├── README.md              ← 本说明
├── index.md               ← 全部卡片索引（最新在上）
├── templates/
│   └── entry-template.md  ← 单卡模板（我复制它来写）
├── _inbox/                ← 你丢原始素材的地方
└── categories/
    ├── AI与方法/
    ├── 创业与变现/
    ├── 技术与工具/
    ├── 行业与趋势/
    └── 个人成长/
```
