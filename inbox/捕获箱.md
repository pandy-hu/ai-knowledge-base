## 路由判定速查（idea-capture 自动判断，并向你提醒）
- → 📥 简报：时效性强 / 有钩子话题性 / 普通人能参与能看懂 / 生活化大众向。
- → 🗺️ 商业认知版图：商业逻辑 / 赚钱模式 / 底层框架 / 需结构化沉淀 / 可蒸馏成方法论。
- → 两者：既是热点又有深层商业逻辑（先蹭热度，再沉淀深度）。

## 平台写作风格（同一内容，不同平台写法不同）
- **免费简报（邮件·公众号风格）**：口语、有观点情绪、移动端、标题≤25字、🔥爆款标注；严禁通稿腔（禁"据悉/近日/值得注意的是"）；末尾元宝点评+星球CTA。
- **付费版（知识星球·机会翻译层）**：💡副业启示 / 🔍信息差 / ✅今日可操作 三层 + Top3机会清单 + 周报预告；直说钱和路径。
- **商业认知版图（知识库·深度）**：轻量→四问卡(①②③④+附)；深度→business-teardown 九模块；数据有出处、口播数字标"谨慎引用"、含🎯对你有没有用+变现适配度打分。
