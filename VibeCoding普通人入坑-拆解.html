1核心论点（视频讲什么）

  • 定义：通过 AI agent 帮你写软件、跑脚本、自动化工作流——把"说"的能力变成"做"。

2从"说"到"做"的三类实战

  • 文件 / 系统操作：清理 C 盘、卸载流氓软件、关 Win 自动更新、配显示器色彩管理、改 Steam host 节点。⚠️ 权限大风险大，让 agent 做时在旁边看着。
  • 办公自动化：批量重命名、Excel 处理、定时抓数据——做成可复用脚本。
  • 造产品：写迷你网页 / 小游戏 / 小工具（你已验证的 web-games 路线就是 Vibe Coding）。
