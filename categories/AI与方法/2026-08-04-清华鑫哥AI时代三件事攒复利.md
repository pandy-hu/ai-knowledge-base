## ① 怎么用（落到你的一人公司 / 副业，含对标差距）

清华鑫哥的三件事，逐条翻译成你**已经在做 / 还差哪块**：

1. **停用"上一代chatbot"，上超级智能体（agentic）**
   - 他的理由：豆包记忆不透明（自动记的不展示、不可审查修改）、网页版DeepSeek根本没记忆，每次复杂任务都要重灌提示词→浪费时间。该用**能直接控制电脑、读写改本地文件、内置MCP的agent**（他点名 Codex、Claude Code，**原话把"work buddy/workbuildinging"列为国内同类**——即你正在用的 WorkBuddy）。
   - **你的现状**：✅ 已经在用 WorkBuddy（被点名背书的工具），而且是 agentic 用法（读文件/跑命令/调Skill/改知识库），不是 chatbot 式问答。这一步你**领先大多数观众**。
   - **严谨补刀**：他"建议停用豆包/DeepSeek"偏标题党——他自己也说"deps很强、豆包母公司人才密度高"。辩证看：日常轻量问答/写文案仍可用它们，**关键是别把它们当"你的AI操作系统"**，真正的个人资产要落在 agentic 工作流+Skill+记忆上（豆包/DeepSeek的对话记忆流失了就是白用）。

2. **疯狂建属于你自己的100个Skill（颗粒度要细）**
   - 他的逻辑：把工作/生活里的独特流程蒸馏成 Skill，**一件小事一个 Skill**（所以累计大几十到100个）；不怕上下文爆炸，因为有"渐进加载机制"——每个 Skill 只注入元数据（名字+触发条件），不注入全文。
   - **你的现状**：✅ 已沉淀 **5个用户级Skill**（ecom-design-sop / ai-film-director-sop / side-hustle-pit-check / kb-sync / sales-triage），且它们的 frontmatter（name+description触发条件）正是"渐进加载只注入元数据"的实例——你无意中已经对齐了他的方法论。
   - **差距**：❌ 数量还远不到100。你目前是"大块头Skill"（每个覆盖一整条业务线），他建议的是更细颗粒（如"写简报标题钩子""牛牛BD开场白生成"这种单点）。下一步可把5个大Skill拆细、并新增高频单点动作。

3. **立刻建记忆系统（飞轮效应攒复利）**
   - 他的逻辑：记忆系统像"个性化Skill"——回答时参考你的职业/兴趣/历史/计划，回复贴合你；**最关键飞轮**：注入个性化信息→得到个性化方案→方案再存回记忆→AI越来越懂你→复利。开始越早，领先时间变个人优势。
   - **你的现状**：✅ 已建三层记忆（云端自动档案 + 用户级 `~/.workbuddy/MEMORY.md` + 项目级 `MEMORY.md` + 每日日志），且 WorkBuddy 的 agent loop 本身就在持续把成果写回记忆。
   - **差距**：❌ "飞轮"还没跑满——你更多是"我让记才记"，没做到"每次产出都自动回流记忆"。可设规则：每次完成 substantive 任务，自动提炼1条通用经验进用户级 MEMORY.md，让飞轮自转。

**对你最该补的一刀**：第2、3条的"数量/飞轮"——你方向全对，差的是**规模**和**自转**。
