## 一句话核心

cangjie-skill 是一个「内容蒸馏器」：把书、长视频、播客转写成一组**可调用 Agent Skills（方法论单元）**，而不是写一篇摘要。本质是「把看过的东西，变成能一句话调出来的工具箱」。

## 原文要点（已抓 GitHub 仓库分析）

- **仓库结构**：`SKILL.md`（元 skill 执行规范）+ `methodology/`（RIA-TV++ 各阶段）+ `extractors/`（5 个并行提取器 prompt）+ `templates/`（SKILL.md/INDEX.md/BOOK_OVERVIEW.md 模板）。协议 MIT，可商用复用。
- **核心流水线 RIA-TV++（七阶段）**：
  1. 整体理解（Adler 分析阅读法）→ `BOOK_OVERVIEW.md`
  2. 并行提取（框架/原则/案例/反例/术语 5 路）
  3. 三重验证筛选（≥2 处佐证 / 有预测力 / 非常识，通过率仅 25-50%）
  4. RIA++ 构造（R 原文/I 重写/A1 案例/A2 触发场景/E 可执行步骤/B 边界盲点）
  5. Zettelkasten 链接 → `INDEX.md`
  6. 压力测试（诱饵题 + 跨 skill 混淆）→ `test-prompts.json`
  7. 交付（安装到 Claude Code / Codex 的 skills 目录）
- **视频蒸馏**：需先借 `video-downloader` skill 把视频转成文本（下载+字幕/ASR），再喂给 cangjie-skill。
- **关键发现**：`kangarooking-skills` 里的 `video-downloader` **支持抖音、B站、YouTube、小红书**，可同时提取「平台原始文案」+「ASR 口播稿」——这正是补上你昨天问的「抖音链接读不到口播稿」痛点的现成方案。

## ① 怎么用（落到你的知识库）

- **升级出卡流程**：把「喂内容→四问卡」升级为「喂内容→蒸馏成 skill」。同一段素材，既存知识（卡），又沉淀方法（skill），知识库从「笔记本」进化成「工具箱」。
- **直接解决抖音提取**：把 `video-downloader` 的思路接进知识库喂料管道（抖音链接→原始文案+口播稿→出卡/蒸馏）。注意它本地需要 `yt-dlp` + ASR（Whisper 或免费 API），属进阶项，先评估再上。
- **变成我的能力**：我（元宝）本就支持 Skill 系统（SKILL.md）。可把 RIA-TV++ 蒸馏法蒸馏成我自己的「内容蒸馏」skill，以后你丢书/视频/播客，我自动走七阶段出 skill——这是本条最实在的落地。
