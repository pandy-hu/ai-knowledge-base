## 一、这个视频在讲什么（核心论点）
- **Vibe Coding 定义**：通过 AI agent（Codex / Claude Code / 元宝 / 豆包等）帮你写软件、跑脚本、自动化工作流的过程。本质是把"说"的能力变成"做"的能力。
- **历史三跳**：① ChatGPT 只会写指南不会上手 → ② 命令行（黑框）是古老的"打代码"入口，AI 擅长写代码让它复活 → ③ 姚舜宇的 **ReAct loop**（做一步→反思→再想下一步）= agent 起点，AI 从"会说话"变"能操作"。豆包手机本质也是手机上的 agent。
- **价格拐点（为什么是现在）**：DeepSeek 把编程价格砍到 1/10；Kimi K3 世界第三。模型半年一跃（K3 演示复刻整个 WinXP 还能玩 GTA），预期要拉满。
- **普通人获益最大**：agent 干掉重复活，但 AI 搜不到"人的生活直觉 / 人情敏感 / 行业经验"——这些上下文只有人有。agent + 人的主观能动性 = 时代答案（辛顿比喻：让 AI 像母亲一样托举我们，而非控制我们）。

## 二、怎么用（你能立刻做的）
- **零成本起步**：用元宝（你已有的免费 agent）替代教程里的 Codex，自然语言让它写小工具 / 网页 / 自动化脚本。不用注册 OpenAI、不用花钱、数据本地。
- **从"说"到"做"的三类实战**（照视频实例）：
  1. **文件 / 系统操作**：清理 C 盘、卸载流氓软件、关 Win 自动更新、配显示器色彩管理、改 Steam host 节点——这类"权限大风险大"，让 agent 做时在旁边看着。
  2. **办公自动化**：批量重命名、Excel 处理、定时抓数据——做成可复用脚本。
  3. **造产品**：写个迷你网页 / 小游戏 / 小工具（你已验证的 web-games 路线就是 Vibe Coding）。
- **心智升级**：别再问"AI 会不会让我失业"，改问"我的生活直觉 + AI 能造出什么别人造不出的东西"。
