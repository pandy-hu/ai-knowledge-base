## 原文要点（我提炼）

### 1. 为什么现在要做「本地优先」知识库
- 背景：豆包下架自有 AI、Claude/Walkup 提费，AI 市场开始「收割」——不续费工作流就被切断。
- 卡帕西（Karpathy）验证过的组合：**AI + Obsidian 本地库**，数据本地、可接任意模型、不被巨头硬控，含金量还在上升。

### 2. 工具就两个
- **Obsidian**：本地 markdown 笔记工具，AI 能直接读本地文件，不用手动整理。
- **AI 引擎**：一个可接任意大模型的插件/框架（教程语音识别成「CCswitch/Copilot」，实际是 Obsidian 里搜 `cloud` 类插件、配 API 接模型；再用 Codex/agent 框架解锁 skill / MCP / 定时）。

### 3. 三大阶段（采集 → 管理 → 任务）
| 阶段 | 教程做法 |
|------|----------|
| ① 信息采集 | 把 GitHub 资讯项目丢给 AI → 每天自动抓热点、去重、打分、生成结构化日报；浏览器装 clipper 一键收藏文章/视频字幕进库 |
| ② 知识管理 | 资料喂给 AI → 沉淀概念/经验/skill；定制「知识迭代系统」自动查冗余、查冲突、沉淀模板方法论 |
| ③ 完成任务 | 一句话让 AI 读本地文件干活（报告/PPT/图视频）；重复 SOP 做成 skill 随调；定时任务自动跑（如每晚整理飞书→日报→周报） |

### 4. 核心理念
- 产出反哺知识库，形成复利；罗马不是一天建成，从「一个很小的工作环节」入手，省下一丢丢时间就值得持续做。

## ① 怎么用

**现在马上能做（你已具备，认出来即可）：**
1. **装 Obsidian 打开 `knowledge-base/` 文件夹**：24 张卡 + 商业拆解即刻可见，本地全文搜索、双向链接、图谱视图。
2. **用元宝/WorkBuddy 当 AI 引擎**：零成本平替教程里的 Codex——你把链接/视频/截图丢给我，我读库、蒸馏成四问卡、出文档、定时跑。
3. **把教程三大阶段映射到你已有体系**：采集=每日简报自动化；管理=四问卡+商业认知版图；任务=一句话让我调 skill/出报告。

**未来能用的（存成知识块）：**
- **知识迭代 Skill**：让元宝定期扫全库，标记冗余/冲突卡，生成「待合并清单」。
- **Obsidian 插件包**：Copilot（库内对话）、QuickAdd+Templater（一键建四问卡）、Dataview（自动生成索引表，替代手动维护 index.md）。
