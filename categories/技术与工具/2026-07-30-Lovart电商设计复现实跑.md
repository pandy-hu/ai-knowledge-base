## 原文要点
- **核心主张**：AI 真正改变的是工作方式——不要手搓提示词，要把经验/流程/方法沉淀成可复用的 Skill。
- **完整 SOP（五阶段）**：
  1. **产品分析**：上传产品图，AI 出属性/目标用户/核心卖点/视觉方向。
  2. **产品基础**：精修图 + 三视图/多角度，建立产品视觉认知。
  3. **视觉展开**：主视觉 → 模特套图 → 营销海报（全比例） → 样机 → 电商主图 → 详情页（分屏）。
  4. **分层交付**：图文分离的 PSD/SVG 给甲方。
  5. **沉淀 Skill**：把以上对话和结果训练为 Custom Skill，下次只给新产品图+介绍即可一键复用。
- **关键技巧**：每一步都**引用前序产物**，保证整套视觉风格统一。

## 实跑验证（2026-07-30，ImageGen 后端）
- 用一张示例护肤精华瓶白底图跑了关键链路：产品图 → 精修图 → 三视图 → 主视觉 → 海报 → 详情页首屏。
- **跑通的**：精修图质感提升明显；主视觉/海报/详情页通过"引用精修图"保持了产品一致性；色调统一。
- **暴露的坑**：
  - 三视图变成"三个同款正面图"，ImageGen 没有真 3D 旋转能力。
  - 海报/详情页里的文字是"伪文字"（乱码/假拉丁），不能直接商用，必须后期替换。
  - 没有 PSD 分层/图文分离。
  - 模特一致性未测，但预期会漂移（需固定模特参考图或 Lovart）。

## ⑤ Skill 缺口补齐（2026-07-30 晚）
- 把视频要求与已落地的 `ecom-design-sop` 逐项核对：结构对齐 ~90%，五阶段 / 引用链 / 资产顺序 / 变现三层 / 沉淀 Skill 元层面对齐。
- **三大真缺口**（ImageGen 物理做不到，需 Lovart / 3D / PS）：① 真·PSD / 分层交付 ② 品牌 DNA 自动记忆（Design Context Core）③ 真三视图多角度一致性。
- **已在 WorkBuddy 内补齐的 5 项**：
  1. `disable: true` → `false`，skill 恢复自动触发（一键复用成立）。
  2. 新增 `references/brand-kit.md`（品牌风格锁定模板），Stage 1 自动注入 → 穷人版 Design Context Core。
  3. Stage 4 交付物升级为**可编辑工程文件**（Canva / Figma / 稿定设计，多图层、文字可改）+ 导出 PNG，替代 PSD 分层。
  4. 补国内工具链「稿定设计 / 创客贴」（支持上传本地底图，比 Canva MCP 更稳）。
  5. 三视图降级为**可选非默认交付**（小商家只需精修图 + 主视觉 + 海报 + 详情页首屏）。
- **仍明确标注需 Lovart 兜底、不硬凑**：真 3D 旋转、原生 PSD / SVG 分层导出、Lovart Custom Skill 训练 + ChatCanvas 圈选改图。
- 结论：视频要求在 WorkBuddy 层面对齐度已 100%（方法论 + 一键复用 + 风格锁定 + 可编辑交付）；仅底层物理能力需 Lovart。
